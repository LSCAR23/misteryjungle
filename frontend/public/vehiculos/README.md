# Imágenes de vehículos

Esta carpeta contiene las fotos reales de los vehículos que muestra la app.

## Cómo agregar una imagen

- Usá PNG **sin fondo** (transparente).
- Tamaño recomendado: **~1200 × 800 px**.
- El vehículo debe estar **mirando hacia la derecha**.
- Usá **exactamente** estos nombres de archivo (minúsculas, con guiones):

| Archivo | Vehículo |
|---|---|
| `honda-navi.png` | Honda Navi |
| `honda-elite.png` | Honda Elite |
| `honda-cbf150s.png` | Honda CBF150S |
| `honda-xr190.png` | Honda XR190 |
| `honda-crf250.png` | Honda CRF250 |
| `honda-crf300-rally.png` | Honda CRF300 Rally |
| `honda-trx-4x4.png` | Honda TRX 4x4 |
| `honda-rincon-4x4.png` | Honda Rincon 4x4 |
| `honda-pioneer-4x4.png` | Honda Pioneer 4x4 |
| `honda-pioneer-deluxe-crew.png` | Honda Pioneer Deluxe Crew |
| `honda-talon-4x4.png` | Honda Talon 4x4 |
| `honda-talon-4wd.png` | Honda Talon 4WD |
| `isuzu-serie-q.png` | Isuzu Serie Q |

## Fallback

Si un archivo no existe, la app muestra la silueta de la categoría correspondiente
(Scooter, Moto, ATV, UTV o Camión) desde la carpeta `placeholders/`.
